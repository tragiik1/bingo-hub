ELDEN RING BINGO

Everything you need for a bingo race, in one folder.


FIRST TIME
  1. Put this folder wherever you like, for example C:\Games\Elden Ring Bingo.
  2. Open "Bingo Hub.exe". If Windows says it protected your PC, click
     "More info", then "Run anyway". That happens because the app isn't signed.
  3. Open the Setup page. Anything red or yellow comes with a button to fix it.
     The Bingo Board needs the .NET 8 Desktop Runtime; Setup links to it if
     it's missing.


RACING
  1. Enter the race seed on the Race page. The host can pick any seed and share it.
  2. Open the Bingo Board and join the lobby.
  3. Open the Randomizer. The seed is already copied: paste it (Ctrl+V) and
     press Randomize. The hub backs up your save when it finishes.
  4. Press Launch in the hub, or Bingo! in the Randomizer. Same thing.
     In the sidebar, Elden Ring should say "Modded". If it says "No mod", the
     game was started from Steam: close it and launch from the hub.


RACE GRACES
  The hub sets the race graces on a new bingo character by itself, on any
  save: from the name screen (where you set the keepsake) or right after you
  press Finish. Windows plays a sound when it's done. No Cheat Engine needed.
  Characters you've already played are never changed automatically.
  If it didn't happen, press Ctrl+F9 in game, or Set graces on the Setup page.


SAVES
  Bingo runs use your normal save file. The hub backs it up whenever the game
  starts (even from the Randomizer's Bingo! button) and can restore any backup
  from the Saves page. The first bingo game after you've played normally also
  keeps a "before bingo" backup that is never cleaned up. Before playing
  online, restore it and launch through Steam. The hub warns you if you start
  the game normally on a save you last used for bingo.


UPDATES
  The hub checks for updates by itself. When one is out, "Update available"
  shows in the sidebar: click it and the hub restarts on the new version.


WHAT'S INSIDE
  Bingo Hub.exe       The hub
  Bingo Board         EldenBingo, the lobby board and map
  Bingo Randomizer    Bingo Randomizer (S2 Style 1.0) with ModEngine 2
  Debug Tool          Elden Ring Debug Tool, for practice only
  Boards              Bingo Brawlers goal lists
  Data, Save Backups  Created on first run: your settings, run log and backups
  LICENSES.txt        Licences and source links for the included tools

The Board, Randomizer, Debug Tool and ModEngine 2 are made by their own authors.
They're included unchanged, except the Randomizer: weapon names from recent
game updates were added so seeds that hand those weapons out don't crash.
