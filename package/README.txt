ELDEN RING BINGO

Everything you need for a bingo race, in one folder.


FIRST TIME
  1. Put this folder wherever you like, for example C:\Games\Elden Ring Bingo.
  2. Open "Bingo Hub.exe". If Windows says it protected your PC, click
     "More info", then "Run anyway". That happens because the app isn't signed.
  3. Open the Setup page. Anything red or yellow comes with a button to fix it.
     The Bingo Board needs the .NET 8 Desktop Runtime; Setup links to it if
     it's missing.


RACING
  1. Enter the race seed on the Race page, or press Generate and share it.
  2. Open the Bingo Board and join the lobby.
  3. Open the Randomizer. The seed is already copied: paste it (Ctrl+V) and
     press Randomize. The hub backs up your save when it finishes.
  4. Press Launch in the hub, or Bingo! in the Randomizer. Same thing.
     In the sidebar, Elden Ring should say "Modded". If it says "No mod", the
     game was started from Steam: close it and launch from the hub.


SAVES
  Bingo runs use your normal save file. The hub keeps backups in "Save Backups"
  and can restore any of them from the Saves page. Before playing online,
  restore a backup from before your bingo runs and launch through Steam.


UPDATES
  The hub checks for updates by itself. When one is out, "Update available"
  shows in the sidebar: click it and the hub restarts on the new version.


WHAT'S INSIDE
  Bingo Hub.exe       The hub
  Bingo Board         EldenBingo, the lobby board and map
  Bingo Randomizer    Bingo Randomizer 0.91 with ModEngine 2
  Debug Tool          Elden Ring Debug Tool, for practice only
  Boards              Bingo Brawlers goal lists
  Data, Save Backups  Created on first run: your settings, run log and backups

The Board, Randomizer, Debug Tool and ModEngine 2 are made by their own authors
and are included unchanged.
